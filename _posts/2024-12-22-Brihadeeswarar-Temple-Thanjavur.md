**Brihadeeswarar Temple** was built in **1010 AD** by **Rajaraja Chola I**. Dedicated to Lord Shiva, still an active temple today, and now a **UNESCO World Heritage Site**.

**Who was Rajaraja Chola I?** One of the greatest Chola kings (ruled around 985 to 1014 AD). He expanded the empire across South India and into Sri Lanka, and made Thanjavur his capital. The temple was his grand offering to Shiva, partly devotion, partly a statement of Chola power. He named the deity **Rajarajeswaram**, after himself. Later it became better known as Brihadeeswarar ("the great Lord").

**What's written on the walls?** Not sure of the details, but from what I've read, the Tamil inscriptions are basically the temple's admin file, carved in granite.

A few interesting things:

- Built in roughly **6 to 7 years** (around 1003 to 1010 CE). For something this size, that's wild.
- The **vimana** (main tower) is about **66 metres** tall, built almost entirely of granite, with no quarry nearby.
- The **kumbam** (the rounded dome at the very top) is a single granite block weighing around **80 tonnes** (80,000 kg). Somehow hauled up there a thousand years ago.
- It's often said that its shadow never falls on the ground within the temple complex at noon. Not sure what's it about. <img class="smiley" src="/assets/img/icons/smile.png">
- Still standing after 1,000+ years.

<script>
(function () {
  var triggers = Array.prototype.slice.call(document.querySelectorAll('.lb-trigger'));
  if (!triggers.length) return;

  var overlay = document.getElementById('lb-overlay');
  var image = document.getElementById('lb-image');
  var caption = document.getElementById('lb-caption');
  var btnClose = document.getElementById('lb-close');
  var btnPrev = document.getElementById('lb-prev');
  var btnNext = document.getElementById('lb-next');
  var index = 0;

  function openAt(i) {
    index = (i + triggers.length) % triggers.length;
    var link = triggers[index];
    image.src = link.getAttribute('href');
    image.alt = (link.querySelector('img') && link.querySelector('img').alt) || '';
    caption.textContent = link.getAttribute('data-caption') || '';
    overlay.classList.add('is-open');
    overlay.setAttribute('aria-hidden', 'false');
    document.body.style.overflow = 'hidden';
  }

  function closeLb() {
    overlay.classList.remove('is-open');
    overlay.setAttribute('aria-hidden', 'true');
    image.src = '';
    document.body.style.overflow = '';
  }

  triggers.forEach(function (link, i) {
    link.addEventListener('click', function (e) {
      e.preventDefault();
      openAt(i);
    });
  });

  btnClose.addEventListener('click', closeLb);
  btnPrev.addEventListener('click', function (e) {
    e.stopPropagation();
    openAt(index - 1);
  });
  btnNext.addEventListener('click', function (e) {
    e.stopPropagation();
    openAt(index + 1);
  });

  overlay.addEventListener('click', function (e) {
    if (e.target === overlay) closeLb();
  });

  document.addEventListener('keydown', function (e) {
    if (!overlay.classList.contains('is-open')) return;
    if (e.key === 'Escape') closeLb();
    if (e.key === 'ArrowLeft') openAt(index - 1);
    if (e.key === 'ArrowRight') openAt(index + 1);
  });
})();
</script>
