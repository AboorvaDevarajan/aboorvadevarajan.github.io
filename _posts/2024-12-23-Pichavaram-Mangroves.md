**Pichavaram, 23 December 2024.** Same day as Chidambaram. Temple in the morning, boat after. <img class="smiley" src="/assets/img/icons/smile.png">

**Pichavaram** is one of India's largest mangrove forests. Often called second after the Sundarbans, from what I've read. It's only about 15 km from Chidambaram, in Cuddalore district, between the Vellar and Coleroon estuaries. About **2,700 acres**, spread over **51 islets**, cut up by canals. You don't walk it. You go by boat. We took a small row boat. Thought slow would be more enjoyable than a motor boat.

**Mangroves** are trees that live in salt water and tidal mud. Most trees would die here. The mud has almost no oxygen, so they grow roots above the water to breathe. Aerial roots. Stilt roots on some, little pencils on others. They also hold the coast together.

During the **2004 tsunami**, villages behind thick mangroves survived much better than those without them.

Those are **stilt roots**. That's **Rhizophora**, the mangrove that grows right along the canals. The trees sit in salt water and mud, so they send roots out into the air to breathe. Not sure of all the biology, but that's the idea. They make a kind of hallway over the water.

Two main kinds here, from what I've read. **Rhizophora** along the water. That's the tunnel, the stilt roots. **Avicennia** more towards land. Those little pencils in the mud are how it breathes.

<script>
(function () {
  var triggers = Array.prototype.slice.call(document.querySelectorAll('.lb-trigger'));
  if (!triggers.length) return;

  var overlay = document.getElementById('lb-overlay');
  var image = document.getElementById('lb-image');
  var caption = document.getElementById('lb-caption');
  var btnClose = document.getElementById('lb-close');
  var btnPrev = document.getElementById('lb-prev');
  var btnNext = document.getElementById('lb-next');
  var index = 0;

  function openAt(i) {
    index = (i + triggers.length) % triggers.length;
    var link = triggers[index];
    image.src = link.getAttribute('href');
    image.alt = (link.querySelector('img') && link.querySelector('img').alt) || '';
    caption.textContent = link.getAttribute('data-caption') || '';
    overlay.classList.add('is-open');
    overlay.setAttribute('aria-hidden', 'false');
    document.body.style.overflow = 'hidden';
  }

  function closeLb() {
    overlay.classList.remove('is-open');
    overlay.setAttribute('aria-hidden', 'true');
    image.src = '';
    document.body.style.overflow = '';
  }

  triggers.forEach(function (link, i) {
    link.addEventListener('click', function (e) {
      e.preventDefault();
      openAt(i);
    });
  });

  btnClose.addEventListener('click', closeLb);
  btnPrev.addEventListener('click', function (e) {
    e.stopPropagation();
    openAt(index - 1);
  });
  btnNext.addEventListener('click', function (e) {
    e.stopPropagation();
    openAt(index + 1);
  });

  overlay.addEventListener('click', function (e) {
    if (e.target === overlay) closeLb();
  });

  document.addEventListener('keydown', function (e) {
    if (!overlay.classList.contains('is-open')) return;
    if (e.key === 'Escape') closeLb();
    if (e.key === 'ArrowLeft') openAt(index - 1);
    if (e.key === 'ArrowRight') openAt(index + 1);
  });
})();
</script>
