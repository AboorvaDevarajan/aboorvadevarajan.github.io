## Linus, in the room

**16 June.** Jasmine Hall 2. [Linus Torvalds](https://ossindia2026.sched.com/event/23e7c3818c45ba16a49e252aa5c1c93c) in conversation with Dirk Hohndel. Linus, in person, under an Open Source Summit India banner. The first time I had seen him directly, not on a screen. Watching him live had been on my bucket list for years. I was so excited. <img class="smiley" src="/assets/img/icons/smile.png"> <img class="smiley" src="/assets/img/icons/emojis/1f632.png" alt="">

A few things that stuck. He hates prepared talks, which is why they do this as a conversation. Twenty years of the same release: no splashy features, a new kernel every nine or ten weeks, Git and email, and he said he is not a programmer anymore. He is a development lead. Rust is interesting, he still likes C, and he likes LLMs for finding bugs and for toy projects, not for hallucinated reports thrown over the fence.

- Trust people, not companies. Code is easy. Personalities are harder.
- They talked for twenty-six minutes without mentioning AI.
- If you find a bug with an LLM, send a patch, and stay in the conversation.

The recording: [Keynote: Linus Torvalds in Conversation with Dirk Hohndel](https://www.youtube.com/watch?v=YKkEe-PxW10).

## The talk, the next afternoon

**17 June. Our talk.** 3:35pm, Lotus Ballroom 3. *[Towards a Tool for Access-Affinity Based Structure Reordering in the Linux Kernel](https://ossindia2026.sched.com/event/2KNHO/towards-a-tool-for-access-affinity-based-structure-reordering-in-the-linux-kernel-madadi-vineeth-reddy-aboorva-devarajan-ibm)*.

The idea in one line: fields accessed close together in time should live close together in memory. We built a small tool around that, kstruct-tuner.

A room full of maintainers and contributors. Exciting, and a little intimidating. The questions, and the feedback, are what I want to carry back into the work.

The Linux Foundation recorded it.

The best conversations were often outside the halls. Coffee, lunch, a table after a session. The line from the day before was to send a patch and stay in the conversation. Sitting in that room, that is what the questions felt like. I left wanting to send a few more patches before the next one.

The next day there was no ballroom and no schedule. We went out to see the city, starting at a museum and walking until we reached the sea. [That became our first walk through South Mumbai](/blog/2026/06/18/South-Mumbai/).

(function () {
  var triggers = Array.prototype.slice.call(document.querySelectorAll('.lb-trigger'));
  if (!triggers.length) return;

  var overlay = document.getElementById('lb-overlay');
  var image = document.getElementById('lb-image');
  var caption = document.getElementById('lb-caption');
  var btnClose = document.getElementById('lb-close');
  var btnPrev = document.getElementById('lb-prev');
  var btnNext = document.getElementById('lb-next');
  var index = 0;

  function openAt(i) {
    index = (i + triggers.length) % triggers.length;
    var link = triggers[index];
    image.src = link.getAttribute('href');
    image.alt = (link.querySelector('img') && link.querySelector('img').alt) || '';
    caption.textContent = link.getAttribute('data-caption') || '';
    overlay.classList.add('is-open');
    overlay.setAttribute('aria-hidden', 'false');
    document.body.style.overflow = 'hidden';
  }

  function closeLb() {
    overlay.classList.remove('is-open');
    overlay.setAttribute('aria-hidden', 'true');
    image.src = '';
    document.body.style.overflow = '';
  }

  triggers.forEach(function (link, i) {
    link.addEventListener('click', function (e) {
      e.preventDefault();
      openAt(i);
    });
  });

  btnClose.addEventListener('click', closeLb);
  btnPrev.addEventListener('click', function (e) {
    e.stopPropagation();
    openAt(index - 1);
  });
  btnNext.addEventListener('click', function (e) {
    e.stopPropagation();
    openAt(index + 1);
  });

  overlay.addEventListener('click', function (e) {
    if (e.target === overlay) closeLb();
  });

  document.addEventListener('keydown', function (e) {
    if (!overlay.classList.contains('is-open')) return;
    if (e.key === 'Escape') closeLb();
    if (e.key === 'ArrowLeft') openAt(index - 1);
    if (e.key === 'ArrowRight') openAt(index + 1);
  });
})();
</script>
