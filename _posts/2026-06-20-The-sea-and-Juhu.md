This last part is not a single day. It is the water that kept returning through the trip: first at the end of [our South Mumbai walk](/blog/2026/06/18/South-Mumbai/), then at Juhu after [Kanheri](/blog/2026/06/19/Kanheri-Caves/), and finally from the plane.

**18 June, evening.** We had reached the sea at the Gateway, but the day did not end there. We stayed with the water as the light changed.

## Buildings, and the sea under them

The city is tall along this coast. Glass, cranes, one tower after another. From the road they fill the sky; from the water they become a line on the far side.

## Juhu, after Kanheri

The next evening, after a day of basalt, caves, and forest, we went to Juhu. The sea was waiting at the other end of the day again.

The beach is beautiful. The sun on the water, people standing in the shallows, a palm over the sand.

Then we looked down at the sand.

Plastic, cloth, a pile of it in a puddle. Someone walking past. The sunset was still there, people were still in the water, and this was the same beach. We were shocked.

We read later what keeps happening here. Waste thrown into drains and nullahs goes out to sea, and high tides push it back onto the shore. Juhu gets the worst of it. After a week of heavy rain this monsoon, the BMC cleared more than 2,500 tonnes of plastic, thermocol, and clothes from Mumbai's beaches. Juhu alone accounted for about 1,824 tonnes. [The Indian Express wrote it up](https://indianexpress.com/article/cities/mumbai/mumbai-beaches-garbage-monsoon-bmc-cleanup-drive-10804833/).

## The next day, from the plane

From the plane, the separate pieces became one coast. Buildings packed to the water, the curve of the bay, ships out on the sea. Beautiful from up there. And we had just stood on the sand where the garbage comes back.

(function () {
  var triggers = Array.prototype.slice.call(document.querySelectorAll('.lb-trigger'));
  if (!triggers.length) return;

  var overlay = document.getElementById('lb-overlay');
  var image = document.getElementById('lb-image');
  var caption = document.getElementById('lb-caption');
  var btnClose = document.getElementById('lb-close');
  var btnPrev = document.getElementById('lb-prev');
  var btnNext = document.getElementById('lb-next');
  var index = 0;

  function openAt(i) {
    index = (i + triggers.length) % triggers.length;
    var link = triggers[index];
    image.src = link.getAttribute('href');
    image.alt = (link.querySelector('img') && link.querySelector('img').alt) || '';
    caption.textContent = link.getAttribute('data-caption') || '';
    overlay.classList.add('is-open');
    overlay.setAttribute('aria-hidden', 'false');
    document.body.style.overflow = 'hidden';
  }

  function closeLb() {
    overlay.classList.remove('is-open');
    overlay.setAttribute('aria-hidden', 'true');
    image.src = '';
    document.body.style.overflow = '';
  }

  triggers.forEach(function (link, i) {
    link.addEventListener('click', function (e) {
      e.preventDefault();
      openAt(i);
    });
  });

  btnClose.addEventListener('click', closeLb);
  btnPrev.addEventListener('click', function (e) {
    e.stopPropagation();
    openAt(index - 1);
  });
  btnNext.addEventListener('click', function (e) {
    e.stopPropagation();
    openAt(index + 1);
  });

  overlay.addEventListener('click', function (e) {
    if (e.target === overlay) closeLb();
  });

  document.addEventListener('keydown', function (e) {
    if (!overlay.classList.contains('is-open')) return;
    if (e.key === 'Escape') closeLb();
    if (e.key === 'ArrowLeft') openAt(index - 1);
    if (e.key === 'ArrowRight') openAt(index + 1);
  });
})();
</script>
